# ML / dataset tooling (offline)

Not imported by the running FastAPI service (`backend/app/`). Used for the
Week 2/3 dataset, structured baseline, and synthetic-narrative work
described in [`../../docs/dataset-and-eda.md`](../../docs/dataset-and-eda.md).

## Setup

```bash
cd backend
source .venv/bin/activate   # created per the root README
pip install -r requirements-ml.txt
```

## Pipeline (run from the repo root)

```bash
python3 backend/ml/data/fetch_dataset.py              # -> data/raw/toddler_autism_qchat10_2018.csv
python3 backend/ml/baseline/train_structured_baseline.py  # -> data/processed/structured_baseline_metrics.json
python3 backend/ml/narratives/generate_narratives.py   # -> data/processed/synthetic_narratives.csv
python3 backend/ml/narratives/validate_narratives.py   # checks narrative/source consistency
python3 backend/ml/narratives/split_dataset.py          # -> data/processed/synthetic_narratives_{train,val,test}.csv
```

`data/raw/` and `data/processed/` are gitignored — everything in them is
regenerated by these scripts, not committed.

## Layout

- `data/fetch_dataset.py` — downloads the public Q-CHAT-10 toddler screening dataset.
- `data/domain_mapping.py` — Q-CHAT-10 item → behavioural-taxonomy domain mapping.
- `data/dataset_split.py` — shared Case_No-based train/val/test split, used by both the baseline and the narrative pipeline so a given record never crosses splits.
- `baseline/train_structured_baseline.py` — Week 2 structured-data baseline (Logistic Regression + SVM).
- `narratives/templates.py` — caregiver-style narrative templates per (domain, status).
- `narratives/generate_narratives.py` — Week 2: renders synthetic narratives from structured records.
- `narratives/validate_narratives.py` — Week 3: checks every narrative traces back to its own (domain, status) template pool.
- `narratives/split_dataset.py` — Week 3: finalises the leakage-safe narrative dataset split.

## Not in scope yet

Week 4 (TF-IDF/embedding-based NLP model training) is intentionally not
started. This directory currently only prepares data and trains the
structured (non-text) baseline.
